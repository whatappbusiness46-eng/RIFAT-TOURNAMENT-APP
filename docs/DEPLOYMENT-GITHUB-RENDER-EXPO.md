# GitHub → Render → Expo APK deployment

## 1. GitHub

1. Create a private GitHub repository.
2. Upload the complete contents of this folder (the repository root is this folder; do not upload the ZIP as the only file).
3. Confirm `.env` and database files are not committed. `.gitignore` excludes them.

## 2. Render

1. In Render, choose **New → Blueprint** and connect the GitHub repository containing `render.yaml`.
2. Review the `rifat-tournament-app` web service and deploy it.
3. In the service Environment page, set `ADMIN_EMAIL` and a strong unique `ADMIN_PASSWORD` (10+ characters). `JWT_SECRET` is generated by the blueprint.
4. After deploy, open `/api/health` on the assigned `onrender.com` URL.
5. Copy the exact service URL. Update `expo-app/app.json` → `expo.extra.apiUrl` to that URL (no trailing slash), then commit/push the change.

**Free-plan warning:** this app currently stores data in SQLite. Render Free's filesystem is ephemeral, so database data can disappear after restarts/redeploys. Use this only as a demo until persistent storage or PostgreSQL migration is completed. Do not use it for real-money activity.

## 3. Expo APK

1. Install Node.js 20+ and run `cd expo-app && npm install`.
2. Run `npx expo-doctor` and `npm test`.
3. Run `npx eas-cli login` with your Expo account.
4. Run `npx eas-cli build --platform android --profile preview`.
5. Download the APK from the EAS build page after the remote build completes.

The EAS build requires the owner's Expo login and network access. This source ZIP cannot contain a signed APK without that account/build.
