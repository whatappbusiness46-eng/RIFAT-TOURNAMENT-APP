BEFORE RUNNING THE RESET WORKFLOW
A. In GitHub repository Settings > Secrets and variables > Actions, add:
   - DATABASE_URL (Supabase PostgreSQL connection string)
   - ADMIN_EMAIL (the admin login email you want after reset)
   - ADMIN_PASSWORD (strong password, at least 12 characters)
   - ADMIN_NAME (optional; e.g. Administrator)
B. Verify DATABASE_URL points to the intended production database.
C. Commit all files at the exact paths above.
D. Open Actions > "ZYROX ARENA - Full database reset and tournament setup".
E. Run workflow, type YES, then confirm.

WARNING: The workflow permanently deletes all app users, wallet balances, deposits,
withdrawals, transactions, match joins, matches, results, notifications, home videos,
rules and settings. It recreates default settings and the admin account, then seeds
200 matches. Do not run unless you accept permanent data loss. Never run the old
"Seed ZYROX ARENA tournaments" workflow after this; this workflow already seeds.

MATCH SETUP
- Original fees, prize pools, player limits, kill rewards and prize splits are preserved.
- Same-fee matches are placed next to each other in exact pairs.
- Every match gets Rules & Regulations.
- If any fee count is odd, seeding stops instead of changing a fee.
- Seeder skips if ZYROX AUTO 2026 matches already exist.
