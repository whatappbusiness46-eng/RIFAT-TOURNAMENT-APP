# ZYROX ARENA PostgreSQL migration bundle

## Included files
- `server/reset-database.js` — explicit one-time full database wipe and default-data reinitialization.
- `server/seed-tournaments.js` — creates 200 matches, fills every match's Rules & Regulations, and sorts matches into adjacent pairs with identical entry fees.
- `APPLY-GUIDE.txt` — safe manual application instructions.

## Important
The reset permanently deletes users, wallets, deposits, withdrawals, transaction history, joined-player records, matches, results, notifications, home videos, rules, and settings in the database named by `DATABASE_URL`.
It is not run automatically by Render or when the app starts.
Do not run it unless you intentionally want to erase all production data.

## Apply
1. Upload/replace `server/reset-database.js` and `server/seed-tournaments.js` in the GitHub repository.
2. Make sure Render's `DATABASE_URL` points to the intended Supabase production database.
3. Run the reset manually once from a trusted shell/environment with:
   `CONFIRM_ZYROX_FULL_RESET=YES node server/reset-database.js`
4. After reset succeeds, seed the 200 tournaments:
   `npm run seed:tournaments`
5. Check Render logs and database records before announcing completion.

Do not run the seed workflow twice. The seeder skips if it detects existing `ZYROX AUTO 2026-` matches.

## Preserved tournament settings
The original entry fees, prize pools, player limits, kill rewards, and prize splits are preserved. Only ordering is changed so equal entry fees are adjacent. If a fee has an odd number of matches, seeding stops rather than changing any fee.
